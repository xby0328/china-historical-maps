# 课程来源与实测笔记

## 课程来源与数据配置

课程：RStata《使用 Python 绘制历年中国各省市区县地图（小地图版本+长版）》。2026-09-22 阅读 Rmd 讲义、模块代码、版权声明，检查图形数据与课程示例。

课程下载后可能有同名嵌套目录。真正资源根目录应直接包含 `provmapdata`、`citymapdata`、`countymapdata`。通过 `--course-root` 或环境变量 `CHINA_MAP_COURSE_ROOT` 指向它；助手也支持外层目录下只有一个有效资源子目录的情况。默认查找当前工作目录的 `course-data`。

- `使用 Python 绘制历年中国各省市区县地图（小地图版本+长版）.Rmd`：八节，从环境、投影到散点、填色、栅格、长版与模块化。
- 同名 HTML：渲染讲义；`draw_china_map.py`：课程模块；`pic1.png`—`pic6.png`：六张参考图。
- `瞪羚、独角兽、创新型企业经纬度数据.xlsx`：37,984 行，37,688 行有经纬度；这些是课程样例，不代表当前企业总体。
- `cn2022.tif`、`NH3_em_anthro_2015_sector_ENE.tif`：夜光和排放示例。文件名不能单独证明年份、产品和单位。
- `LXGWWenKai-Regular.ttf`：课程字体，本地注册使用，不复制到 Skill。
- `版权声明.pdf`：课程、代码、数据限制个人会员使用。Skill 存方法摘要与新写辅助程序，原素材留在用户本机，不附进分发包。

## 文件与字段

文件模板：`{level}mapdata/{version}shp/china{level}{year}{version}/china{level}{year}{version}.shp`；同目录 `_line.shp` 是线层。level 为 prov/city/county；version 为 mini/long。

实查六个目录均有 1949—2021 每年面文件，共 438 个，文件名年份无缺口；这不代表全部年份的几何和属性已审查。使用任一年需检查 shp/shx/dbf/prj 等配套文件。

| 层级 | 连接代码 | 名称 | 2019 原始行数 | 2019 有代码图形数 |
|---|---|---|---:|---:|
| 省 | 省代码 | 省 | 37 | 35 |
| 市 | 市代码 | 市 | 373 | 371 |
| 县 | PAC | NAME | 2902 | 2900 |

2019 mini/long 的字段一致。县级另含省、市代码及名称。代码在 shp 中常被读成浮点数，连接时将 `110000.0` 规范为字符串 `110000`，拒绝非整数/不合法代码。不要假定县字段叫“县代码”。原始文件还混有指北针、比例尺多边形，需按行政层级代码非空筛掉。

2019 省级 `150000` 同时对应“内蒙古自治区”和“中朝共有”：是源属性冲突，不能将第二块自动计入内蒙古指标或静默 dissolve。2019 县级 `710024` 对应“苗栗县”和一块名称缺失的图形。助手输出冲突清单，对同码冲突中名称含“共有”或缺名称的图形保留轮廓、留空专题值；若其余仍有多个普通名称，停止合并，要求有证据的映射。县级 2900 个图形仅 2899 个唯一代码，缺名称不等于可删除几何。

2019 线层 `class` 有行政边界、九段线、海岸线、秦岭-淮河线、胡焕庸线、指北针、比例尺；mini 额外含小地图框格。默认仅叠加海岸线、九段线和 mini 框；胡焕庸线等专题线按需添加。

## 坐标与小地图

原投影：`+proj=aea +lat_0=0 +lon_0=105 +lat_1=25 +lat_2=47 +x_0=0 +y_0=0 +datum=WGS84 +units=m +no_defs`。

源南海矩形（投影米）：xmin=120000，xmax=1766004.1，ymin=320000，ymax=2557786.0。显示转换等价于 `x_display=0.5*x+2100000`、`y_display=0.5*y+1665139`。这是**课程专用版式参数**，不可套给外部底图。

mini 已有大陆、岛屿及插图副本；海南、广东等同时出现在主图与小图。对叠加层先在 long 中国几何裁剪，再保留主图可见部分，复制南海矩形内的**交集**做上述变换，最后裁剪到 mini 显示几何。必须先裁剪再变换多边形，不能仅检查 intersects 就把整个跨框多边形复制。显示副本不参与统计。

## 对课程代码的修正

- `read_point_data` 只删除经度缺失；助手同时检查纬度、数值有限性与坐标范围。
- 填色函数先 `fillna(0)` 再 `+1`，掩盖未匹配和缺失；助手保留缺失，拒绝不适用的 log。
- `log_scale=False` 令 norm=None 后仍访问 norm.vmin，会报错；助手线性模式也创建 norm。
- 原色条以线性渐变手绘，没有共享 LogNorm，还可能由 imshow 改变轴比例；助手使用 ScalarMappable + fig.colorbar + equal aspect。
- `plot_mini_choropleth_discrete` 实际仍连续着色；助手用真实分段边界。
- scico 名称被映射成 Matplotlib 其他色板，不能称为原 scico 配色；助手直接记录实际 cmap 名。
- main 示例混用 2019 省界与 2021 市界；助手统一 boundary year，数据年独立标注。
- 栅格降采样不能简单乘整数 factor：宽高非整除或有旋转时应使用实际新旧尺寸比更新完整仿射变换。
- 原流程将所有非正栅格值删掉，并可能遗漏浮点 nodata；助手用 masked read，保留合法零与负值，按选定色标另行判断。
- 栅格多边形化显式用兼容的 float32/int32 等 dtype；保留 nodata mask，避免依赖各版本对 float64 的支持。
- 原 `vmedian` 是对数范围中点，不是样本中位数；不能照抄统计解释。
- 原北箭头固定向上只表示图上方向；需要真北时按标注位置投影地理子午线求方向。Albers 等面积不等于等距离，比例尺必须说明局部近似且不适用于缩小插图。

辅助代码是面向复用的新实现，不修改课程任何文件。保留真实资料来源，不把原讲义的“绘图：RStata”硬编码为用户新图作者。
